    우리가 찾은 빗물받이

    동그라미를 누르면 사진을 볼 수 있어요. 숫자는 조사한 순서예요.

    👩‍🏫 선생님 메뉴
    🆕 기존 버전과 달라진 점 (수정 시안)

    각 항목의 [ ]는 관련 차시예요. 기존 버전: ysuhj.github.io/gogoschoolseoul

    1. 밖에서 조사, 교실에서 원인 살펴보기 [4~5, 9~10, 11~12차시]
      기존: 원인까지 밖에서 한 번에 기록
      변경: 밖에서는 사진 → 위치 → 막힌 정도 → 쓰레기 → 주변(여러 개)까지 기록해요. 교실에서 📸 조사하기 탭 위쪽의 🤔 원인 살펴보기를 눌러, 사진과 기록을 보며 원인(여러 개)과 까닭을 적어요. 원인이 아직 없는 기록은 어느 기기에서나 적을 수 있어요.
    2. 기록 고치기·지우기 [4~5, 9~10차시 활동2]
      기존: 저장만 되고 고칠 수 없음
      변경: 기록을 눌러 ✏️ 고치기 / 🗑️ 지우기. 만든 기기(모둠)와 선생님만 할 수 있어요. 지운 기록은 시트에 남아 되살릴 수 있어요.
    3. 막힘 상태 3단계로 통일 [2~3, 4~5차시]
      기존: 깨끗해요·조금 있어요·많이 쌓였어요·꽉 막혔어요 (4단계)
      변경: 😀 원활해요 · 😟 일부 막혔어요 · 😱 많이 막혔어요. 과정안의 '원활함/일부 막힘/많이 막힘'과 같은 말이에요. 기준(색칠 25%·55%)은 설정에서 바꿀 수 있어요.
    4. 수업과 가족 과제 구분 [4~5, 9~10차시]
      기존: 수업 시간 조사와 과제가 한 자료에 섞임
      변경: 첫 화면에서 👫 모둠 친구들과 함께해요 / 👨‍👩‍👧 가족과 함께해요 중 하나를 골라요. 지도·결과의 "누구와" 보기와 CSV에서 수업 시간과 가족 과제를 나눠 볼 수 있어요.
    5. 연습 모드 [2~3차시 활동3]
      기존: 예시 입력도 실제 자료에 섞임
      변경: '✏️ 연습' 기록은 결과에서 빠지고, 선생님이 한 번에 지울 수 있어요.
    6. 4학년 새싹반 전용 [전 차시]
      기존: 모든 반이 한 자료를 함께 씀, 모둠 3개 고정
      변경: 기록은 4학년 새싹반 자료로만 모여요. 모둠 수는 6개이고, 주소 끝에 ?groups=4처럼 붙여 바꿀 수 있어요.
    7. 원인 추론 단계 추가 [1, 6~7, 11~12차시]
      기존: 메모 칸만 있음
      변경: '왜 이렇게 되었을까?' 단계에서 생각한 원인을 고르고, 그렇게 생각한 까닭(본 것)을 적어요. 사실과 추측을 나누어 기록하는 연습이 되고, 결과 화면에서 원인별로 모아 볼 수 있어요.
    8. CSV 내려받기 [6~7차시 4수05-03, 14~15차시]
      기존: 앱이 만든 그래프만 볼 수 있음
      변경: 결과 화면에서 원자료를 표(CSV)로 받아 학생이 직접 표·그래프를 만들 수 있어요. 엑셀에서 한글이 깨지지 않아요.
    9. 지도 필터와 색 숨기기 [6~7, 11~12차시]
      기존: 모둠·쓰레기 종류 필터만 있음, 색과 범례가 정해져 있음
      변경: 단계·모둠·상태·주변·쓰레기로 거를 수 있어요. '🎨 색 숨기기'를 누르면 학생이 직접 색·기호와 범례를 정하는 활동을 할 수 있어요.
    10. 가장 많이 막힌 곳 TOP 3 [11~12차시 활동2]
      변경: 결과 화면에서 핫스팟 분석을 시작할 장소를 바로 보여 줘요.
    11. 자료 점검과 중복 알림 [4~5, 9~10차시 활동2]
      기존: 점검 기능 없음
      변경: 5m 안에 같은 단계의 기록이 있으면 위치를 고를 때 미리 알려 줘요. 결과 화면 '🔍 우리 자료 점검하기'에서 중복 의심, 주변 환경 빠짐, 원인 빠짐, 사진 없음을 모아 보여 줘요.
    12. 개인정보 확인 [2~3, 4~5차시]
      기존: 촬영 화면에 안내 없음
      변경: 약속에 '얼굴·번호판 찍지 않기'를 더했고, 사진마다 '얼굴·번호판이 없어요'를 눌러야 다음으로 넘어가요.
    13. 인터넷이 끊겨도 기록 보관 [9~10차시 현장 조사]
      기존: 저장 실패 시 다시 눌러야 하고, 새로고침하면 입력이 사라짐
      변경: 작성 중인 내용은 자동으로 임시 저장되고, 저장할 때 인터넷이 안 되면 기기에 보관했다가 연결되면 저절로 보내요.
    14. 번호 고정
      기존: 기록이 지워지면 뒤 번호가 당겨짐
      변경: 저장할 때 받은 번호가 바뀌지 않아서, 토의 중에 '3번 빗물받이'라고 말해도 헷갈리지 않아요.
    15. 주변 환경 꼭 고르기 [6~7, 11~12차시]
      기존: 고르지 않아도 저장됨
      변경: 환경별 분석에 꼭 필요해서 하나를 골라야 넘어가요.
